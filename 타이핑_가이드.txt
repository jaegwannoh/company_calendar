 하루콩 - 직접 타이핑 가이드
==============================================================

회사 PC(인터넷 없음)에서 메모장으로 코드를 직접 쳐서 만드는 순서와
주의사항입니다. 위에서부터 순서대로 따라 하세요.


--------------------------------------------------------------
 0. 준비물 확인 (회사 PC)
--------------------------------------------------------------

  - Anaconda2 (Python 2.7) 가 C:\Anaconda2 에 설치되어 있어야 함
  - cmd 창에서 아래 한 줄을 실행해서 숫자가 나오면 OK

      C:\Anaconda2\python.exe -c "import sip, PyQt4; print sip.SIP_VERSION_STR"


--------------------------------------------------------------

--------------------------------------------------------------

  * 경로에 한글이 없는 곳을 권장합니다. (바탕 화면, 내 문서 X)
  * data, backup 폴더는 처음 실행할 때 자동으로 생깁니다. 만들지 마세요.

  최종 모습:

          debug.bat


--------------------------------------------------------------
 2. 타이핑 순서 (우선순위)
--------------------------------------------------------------

  순서   파일            줄 수(빈 줄 제외)  내용
  ----   -------------   ----------------  ---------------------------
   1     hk_data.py          약 196줄       DB, 일과 파일, 백업, 공휴일
   2     hk_dialogs.py       약 460줄       일정창, 일과창, 출력, 설정
   3     harukong.py         약 380줄       달력 화면 (실행 파일)
   4     run.bat, debug.bat  각 3~4줄       실행용

  이 순서인 이유:
  - hk_data.py 는 화면이 없어서 가장 단순하고, 다른 두 파일이 이걸 씁니다.
  - harukong.py 가 나머지 두 파일을 불러오므로 마지막에 쳐야 실행됩니다.

  ** 파일 하나를 다 치면 바로 "3. 파일별 오타 검사" 를 하세요. **
  1000줄을 다 치고 한꺼번에 오류를 찾는 것보다 훨씬 쉽습니다.


--------------------------------------------------------------
 3. 파일별 오타 검사 (파일 하나 끝낼 때마다)
--------------------------------------------------------------

  cmd 창에서:

      cd /d C:\harukong
      C:\Anaconda2\python.exe -m py_compile hk_data.py

  아무것도 안 나오면 문법 OK.
  오류가 나오면 "line 숫자" 를 보고 메모장에서 Ctrl+G 로 그 줄로 이동.
  (hk_dialogs.py, harukong.py 도 같은 방법)

  * 이 검사는 "문법" 오타만 찾습니다. 변수 이름 오타는 실행해봐야 나옵니다.


--------------------------------------------------------------
 4. 메모장 사용법 (가장 중요)
--------------------------------------------------------------

  [저장할 때]
  - 파일 > 다른 이름으로 저장
  - 파일 형식: "모든 파일 (*.*)"   ← 안 하면 hk_data.py.txt 가 됨
  - 인코딩: "UTF-8"               ← ANSI 로 저장하면 한글이 깨져서 실행 안 됨

  [보기 설정]
  - 보기 > 상태 표시줄 켜기 → 오른쪽 아래에 줄 번호(Ln) 가 보임
  - 서식 > 자동 줄 바꿈 끄기 → Ctrl+G (줄 이동) 가 동작함


--------------------------------------------------------------
 5. 타이핑 주의사항
--------------------------------------------------------------

  [반드시 지킬 것]
  1) 각 파일 첫 줄  # -*- coding: utf-8 -*-  은 꼭 쳐야 합니다.
     (# 으로 시작하지만 설명이 아니라 "한글 사용" 설정입니다)

  2) 들여쓰기는 스페이스 4칸만. 탭(Tab) 키 쓰지 마세요.
     탭과 스페이스가 섞이면 눈으로는 같아 보여도 오류가 납니다.

  3) 대소문자 정확히: QPushButton, setObjectName, QFontMetrics 등
     파이썬은 대소문자를 구분합니다.

  4) 줄 끝의 콜론(:) 빠뜨리지 않기
     def, class, if, else, elif, for, while, with, try, except 줄 끝

  5) 괄호 짝 맞추기 ( ) [ ] { }
     괄호가 안 닫히면 오류가 "다음 줄" 에서 납니다. 오류 줄 위를 보세요.

  6) 따옴표 짝 맞추기 ' ' 와 " "
     harukong.py 의 STYLE = ''' ... ''' 는 작은따옴표 3개씩입니다.

  [안 쳐도 되는 것]
  - # 으로 시작하는 설명 주석 (첫 줄 coding 줄만 제외)
    예: # 글꼴은 한 번 만들어서 재사용 (속도)
  - 빈 줄 (Enter 만 치면 됨, 몇 줄인지 정확히 안 맞아도 됨)
    단, def / class 사이의 빈 줄은 읽기 쉽게 남기는 걸 추천

  [줄이 길어서 나뉜 곳]
  - 괄호 ( 가 안 닫힌 채로 다음 줄로 넘어가는 곳은 한 줄로 이어서 쳐도
    되고, 원본처럼 나눠서 쳐도 됩니다. 둘 다 동작합니다.

  [특수문자 입력]  메모장에서 "ㅁ" 치고 한자 키
  - ▲ ▼ (일정 순서 버튼)     - ✓ (색 선택 표시)
  - · (가운뎃점, 요약줄과 말풍선)
  * 찾기 어려우면 다른 글자로 바꿔도 동작합니다.
    예: '▲' → '위',  '✓' → 'V',  '·' → '-'

  [자주 헷갈리는 글자]
  - 숫자 0 과 영문 O,  숫자 1 과 영문 l (엘)
  - 언더바 _ 두 개:  __init__ , __name__ , __main__ , __future__
  - '%02d' 는 퍼센트, 숫자0, 숫자2, 영문d


--------------------------------------------------------------
 6. 실행 파일 만들기
--------------------------------------------------------------

  run.bat   (평소 사용, 검은 창 안 뜸)
      @echo off
      cd /d %~dp0
      start "" C:\Anaconda2\pythonw.exe harukong.py

  debug.bat (처음 실행 / 오류 확인용, 검은 창에 오류 표시)
      @echo off
      cd /d %~dp0
      C:\Anaconda2\python.exe harukong.py
      pause

  * .bat 파일은 인코딩 "ANSI" 로 저장해도 됩니다 (한글 없음).


--------------------------------------------------------------
 7. 처음 실행
--------------------------------------------------------------

  1) debug.bat 더블클릭
  2) 오류가 나면 검은 창에 마지막 몇 줄을 봅니다:
       File "hk_dialogs.py", line 123    ← 파일 이름과 줄 번호
       NameError: name 'QPushButon' ...  ← 무엇이 틀렸는지
  3) 그 파일, 그 줄을 고치고 다시 debug.bat
  4) 달력이 뜨면 성공 → 이후에는 run.bat 사용

  * 실행 중에 오류가 나면 메시지창이 뜨고 data\error.log 에도 기록됩니다.
    해결이 안 되면 error.log 내용을 보여주세요.


--------------------------------------------------------------
 8. 기능별 확인 순서 (달력이 뜬 뒤)
--------------------------------------------------------------

  [ ] < > 로 달 이동, [오늘] 버튼
  [ ] 날짜 더블클릭 → 일정창 → 시간 0930 + 할 일 + Enter 로 추가
  [ ] 하루 표시에 "당직" 입력 → [확인] → 달력에 알약 모양으로 표시
  [ ] 날짜 우클릭 → 하루 일과창 → Ctrl+D 로 오늘 날짜 넣기
  [ ] 칸에 마우스를 올리고 잠시 → 말풍선
  [ ] [출력] → 하루 일과 / 일정 → 메모장으로 열림
  [ ] [설정] → 테마, 글꼴 바꾸기
  [ ] 프로그램 종료 후 다시 실행 → 내용이 그대로 있는지

  하나씩 확인하면서 안 되는 기능이 있으면 그 기능이 있는 함수를
  원본과 한 글자씩 비교하세요.
